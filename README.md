# Mandi Price Intelligence System

## Project Overview
The Mandi Price Intelligence System is a Machine Learning based project that analyzes historical agricultural commodity prices and helps estimate mandi prices.

## Objectives
- Analyze agricultural commodity price trends.
- Understand price variations across different mandis and states.
- Predict commodity prices using Machine Learning.
- Visualize price patterns through graphs.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Spyder IDE

## Machine Learning Models
- Linear Regression
- Polynomial Regression
- Decision Tree
- Random Forest
- Support Vector Regression (SVR)
- K-Means Clustering

## Dataset
Historical mandi price data containing commodity, state, market, minimum price, maximum price and modal price.

## Evaluation Metrics
- MAE
- RMSE
- R² Score

## Project Structure
- Dataset files
- Python source code
- Graphs and visualizations

## How to Run
1. Clone this repository.
2. Install required libraries.
3. Run the Python source file.
